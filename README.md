# Messagerie_Instananee
Projet de développement d'une application de messagerie instantanée permettant aux utilisateurs de communiquer en temps réel.

## Architecture
Le projet utilise une architecture monolithique : les différentes fonctionnalités de l'application sont regroupées dans une seule application.

## Fonctionnalités
Création et gestion des utilisateurs
Envoi de messages
Réception de messages
Conversations entre utilisateurs
Messagerie en temps réel

## Technologies
Les technologies utilisées seront ajoutées au fur et à mesure du développement.

## Installation
Les instructions d'installation et de lancement du projet seront ajoutées prochainement.

## Équipe
Projet réalisé en collaboration par les membres de l'équipe.
